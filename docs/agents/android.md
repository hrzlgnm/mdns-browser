# Android Builds

## Commands

```bash
# Generate the Android project (only needed once, or after adding/removing plugins)
pnpm tauri android init

# Overlay the committed launcher icons (also runs in CI after every init)
cp -a src-tauri/icons/android/mipmap-* src-tauri/gen/android/app/src/main/res/

# Build the Android app (APK + AAB)
# The Tauri CLI sets up the NDK cross-compilation environment - always build via this
# Restrict to the x86_64 ABI to keep local verification builds quick (only used for local verification;
# shipping releases are built for the aarch64 and armv7 ABIs)
pnpm tauri android build --debug -t x86_64
```

## Notes

- `src-tauri/gen/android/` is generated and gitignored; do not edit files there manually, they are regenerated by `pnpm tauri android init`.
- `src-tauri/icons/android/` and `src-tauri/icons/ios/` are committed; after `android init` copy the Android icons over the generated res with the `cp -a` above. Do not regenerate with `pnpm tauri icon` - it crops the artwork and looks bad on Android.
- Building from a bare shell with `cargo build --target <android-target>` fails because the NDK cross-compiler env vars (e.g. `CC_aarch64_linux_android`) are unset - always use `pnpm tauri android build`.
