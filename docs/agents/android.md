# Android Builds

## Commands

```bash
# Generate the Android project (only needed once, or after adding/removing plugins)
cargo tauri android init --ci

# Build the Android app (APK + AAB)
# The Tauri CLI sets up the NDK cross-compilation environment - always build via this
# Restrict to the x86_64 ABI to keep local verification builds quick (only used for local verification;
# shipping releases are built for the aarch64 and armv7 ABIs)
cargo --locked tauri android build --target x86_64
```

## Notes

- `src-tauri/gen/android/` is generated and gitignored; do not edit files there manually, they are regenerated by `cargo tauri android init --ci`.
- Building from a bare shell with `cargo build --target <android-target>` fails because the NDK cross-compiler env vars (e.g. `CC_aarch64_linux_android`) are unset - always use `cargo tauri android build`.
